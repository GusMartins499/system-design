## Resumo rápido: SQL vs. NoSQL

| Critério     | SQL                                    | NoSQL                                |
| ------------ | -------------------------------------- | ------------------------------------ |
| Estrutura    | Tabelas, schema fixo (schema-on-write) | Schema flexível                      |
| Garantias    | ACID                                   | ACID não obrigatório                 |
| Ponto forte  | Consistência e integridade             | Velocidade de escrita, flexibilidade |
| Casos de uso | Financeiro, marketplace, CRM, ERP      | Logs, cache                          |
