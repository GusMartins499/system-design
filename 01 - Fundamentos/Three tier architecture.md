## Three tier architecture

Basicamente, system design é traduzir os requisitos em um plano. O básico do system design é a **three tier architecture**:

| Camada       | Responsabilidade      | Onde roda |
| ------------ | --------------------- | --------- |
| Presentation | Frontend, UI/UX       | Client    |
| Lógica       | Regras de negócio     | Server    |
| Dados        | Persistência          | DB        |
